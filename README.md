# Google Drive 权限管理与自动巡检 Chrome 扩展

这是纯前端 Chrome Manifest V3 扩展文件夹，无需 Node 构建或打包 CRX。点击工具栏图标会在独立标签页打开完整的**权限管理与自动巡检中心**。

## 核心功能

1. **直接导入桌面 OAuth JSON 授权 & 多账号同时管理**
   - 无需手动修改 `manifest.json`：直接点击右上角 **「🔑 导入桌面 JSON 授权」**，选择从 Google Cloud 下载的桌面端（`installed`）或 Web 端（`web`）OAuth JSON 文件即可完成登录授权并自动保存长效 `refresh_token`。
   - 支持同时授权和切换多个 Google 账号（或选择「🌐 全部已授权账号」合并扫描与统一管理）。

2. **从表格导入「A列名称 + B列邮箱 + 分组」并按组对应与授权**
   - **三种导入方式**：
     1. **直接从 Excel / Google 表格框选复制粘贴**：支持 `A列名称 + B列邮箱 + 可选C列组名（如 1组、2组）`；
     2. **上传 CSV / TSV 表格文件**；
     3. **直接选择已扫描到的 Google 表格（或输入表格链接）一键同步人员名单**。
   - **直观对应展示**：
     - 文件列表自动将冷冰冰的邮箱显示为 **`[1组] 张三 (zhangsan@gmail.com)`**；
     - 每个文件直观显示 **「已授权分组覆盖情况」**（如 `👥 1组: 5/5人`、`👥 2组: 2/5人 [+补齐]`），一眼看出哪个文件给哪个组开了权限、有没有漏人。
   - **按组一键授权 / 对齐 / 撤权**：
     - 勾选文件后，直接勾选 `1组`、`2组`，即可一键执行：**「➕ 给选中文件授此组权限」**、**「🎯 仅保留所选组权限（移除组外人员）」** 或 **「🗑️ 移除所选组权限」**。

3. **高级智能搜索、关键词排除、不规范文件名归并 & 文件类型包含/排除**
   - **包含关键词**：支持多词 `任一匹配 (OR)`、`同时包含 (AND)` 以及 **智能模糊匹配**（忽略标点、空格、横杠与间隔字符，支持同时搜文件名、核心词根、姓名、邮箱、组名）。
   - **排除关键词**：输入要排除的词，或点击快捷排除按钮（一键排除 `副本`、`Copy`、`备份`、`测试`、`模板`、`旧/废弃`）。
   - **不规范文件名智能归并**：
     - 自动剥离日期、版本号、`副本`、`(1)` 等后缀提取**核心词根（Core Name）**；
     - 支持 **「🧩 按核心名称聚合排序」**（把名字不规范但同系列的表紧挨着排列，并显示 `🧩 同系列(N)` 标签，点击即可只看该系列）以及 **「⚠️ 仅看名字含重复词或副本的文件」**。
   - **文件类型多选【包含 / 排除】**：
     - 细分 8 类（`📊 Google 表格`、`📗 Excel/CSV`、`📝 Google 文档`、`📕 Word/PDF`、`📽️ 幻灯片`、`📁 文件夹`、`🖼️ 图片/音视频`、`📦 压缩包/其他`），可随时切换「仅看勾选类型」或「🚫 排除勾选类型」。
   - **常用筛选预设**：支持将复杂的筛选组合保存为预设标签，下次一键应用。

4. **双层白名单（可编辑 vs 仅查看）与后台定期自动巡检**
   - 区分 **✏️ 允许编辑白名单** 与 **👁️ 仅限查看白名单**（只读名单成员若拥有编辑权将自动识别为 **🟠 越权** 并降级为只读，而非直接踢出）。
   - 支持后台定时扫描（15分钟 ~ 24小时），并可切换 **「🔔 仅告警提醒」** 或 **「⚡ 后台全自动修正 + 留存日志」**，所有变更支持在日志页 **「↩️ 一键恢复原权限」**。

## 当前目录文件

- `manifest.json`：Manifest V3 扩展配置与权限声明。
- `core.js`：核心引擎（桌面 OAuth JSON 授权、多账号令牌刷新、人员分组通讯录、按组批量授权、不规范文件名词根提取与模糊搜索、双层白名单合规评估）。
- `background.js`：后台 Service Worker（定时巡检调度、自动守护执行、桌面通知与扩展角标更新）。
- `popup.html` / `popup.css`：工作台界面与样式。
- `popup.js`：前端交互与状态管理。
