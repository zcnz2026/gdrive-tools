# Google Drive 权限管理与自动巡检 Chrome 扩展

这是纯前端 Chrome Manifest V3 扩展文件夹，无需 Node 构建或打包 CRX。点击工具栏图标会在独立标签页打开完整的**权限管理与自动巡检中心**。

## 核心功能

1. **全文件覆盖与智能筛选（含新增表格/文件识别）**
   - 扫描当前 Google 账号拥有的全部文件与表格，自动对比历史快照并为新创建的表格/文件打上 `NEW 新增` 标签。
   - 支持按文件类型（Google 表格 / 文件夹 / 文档 / 幻灯片 / 其他）、合规状态（非白名单违规 / 越权编辑 / 公开链接 / 已共享）及关键字实时筛选。
   - 顶部提供 6 张交互式统计看板卡片，点击卡片即可一键过滤对应风险文件。

2. **双层白名单与越权自动降级（区分「可编辑」与「仅查看」）**
   - **✏️ 允许编辑白名单 (`writers`)**：允许拥有 `可编辑 (writer)`、`可评论 (commenter)` 或 `仅查看 (reader)` 权限。
   - **👁️ 仅限查看白名单 (`readers`)**：最高仅允许 `仅查看 (reader)` 权限。一旦发现其拥有编辑或评论权，自动标记为 **🟠 越权编辑**，修正时自动调用 Drive API 将其**降级为只读**，而非粗暴踢出。
   - **🚫 名单外人员**：不在上述两个白名单内的协作者，标记为 **🔴 违规外部人员**，修正时自动移除权限。
   - 支持精确邮箱（`user@example.com`）与域名通配符（`@company.com`），配置持久保存在 `chrome.storage.local`。

3. **双视图精细化管控（按文件 + 按协作者）**
   - **📋 按文件管理**：在文件行内直接下拉修改单个协作者的角色（可编辑 / 可评论 / 仅查看）、一键移除单人、一键将陌生人加入白名单，或为文件添加新协作者。
   - **👤 按协作者管理**：按人员邮箱汇总其能访问的所有文件数量与权限分布，支持一键切换某人的白名单身份、一键将其在所有文件中的权限**全部降为只读**或**全部移除**。

4. **后台定期扫描与自动处置开关**
   - 基于 `chrome.alarms` + `chrome.notifications` 支持每 15 分钟 / 30 分钟 / 1 小时 / 6 小时 / 12 小时 / 24 小时后台自动巡检。
   - **两种处置模式可随时切换**：
     - 🔔 **仅告警提醒模式**：发现异常权限或新增风险文件时，在扩展图标显示红色数字角标并发送系统桌面通知，由人工确认后一键修正。
     - ⚡ **后台全自动修正模式**：定时扫描发现非白名单人员立即自动移除，发现只读白名单人员越权立即自动降为只读，并全程写入审计日志。

5. **巡检与操作日志（支持「一键恢复原权限」）**
   - 记录所有手动操作、自动守护修正及定时巡检结果。
   - 若发生误删或误降级，可在日志页点击 **「↩️ 恢复原权限」** 自动调用 API 恢复该人员原有的角色权限。

## 本机加载与配置

1. 在 Google Cloud Console 创建项目、启用 **Google Drive API**，并创建 **Chrome 扩展** 类型的 OAuth 客户端（绑定固定扩展 ID：`bgocffjafnfejbgegebhmdaolegcdfag`）。
2. 将客户端 ID 填入 `manifest.json` 的 `oauth2.client_id`。
3. 打开 `chrome://extensions` 并开启右上角「开发者模式」，点击「加载已解压的扩展程序」选择本目录。
4. 点击浏览器工具栏扩展图标打开管理中心，点击「授权 / 刷新令牌」后即可开始扫描与配置。

## JSON 白名单导入格式

支持新版双层白名单格式：

```json
{
  "writers": ["editor@example.com", "@trusted-team.com"],
  "readers": ["viewer@example.com", "partner@external.com"],
  "publicLinkRule": "forbid"
}
```

同时也向下兼容旧版单数组格式（导入时会提示选择归入「允许编辑」还是「仅限查看」）：

```json
["person@example.com", "team@example.com"]
```

## 当前目录文件

- `manifest.json`：Manifest V3 扩展配置与权限声明（`identity`, `storage`, `alarms`, `notifications`）。
- `core.js`：共享核心引擎（Drive API 封装、双层白名单合规评估、批量/自动修正执行器、本地存储与审计日志管理）。
- `background.js`：后台 Service Worker（定时巡检调度、自动守护执行、桌面通知与扩展角标更新）。
- `popup.html` / `popup.css`：四视图工作台界面与响应式样式。
- `popup.js`：前端交互逻辑（按文件/按人员双视图、行内改权限、白名单可视化配置、日志回滚与报表导出）。
